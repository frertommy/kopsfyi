Index methodology

Claims lead the print.

01

Claims come out first

Jobless-claims filings are reported weekly — well before the monthly jobs report. How they change month-to-month is the main input to the forecast.

02

Anchored to the trend

The recent run of jobs numbers sets the baseline; the claims signal nudges it up or down. Claims alone can only do so much — so the range is honestly wide.

03

Settles to the first report

It settles to the first official BLS jobs number — the one the market reacts to. Later revisions count only lightly.

Why now

The jobs number, before the jobs number.

The monthly jobs report moves markets more than almost any number — and you get it once a month, revised twice after. In between, desks guess from ADP, from claims, from vibes. Each is a fragment; none is the payroll number itself, early.

So everyone positions into the print half-blind.

JOBSNOW reads the jobless-claims data that prints first and turns it into a continuous payrolls nowcast. It doesn’t wait for release day; it tracks where payrolls are heading and settles to the first official jobs number when it lands.
